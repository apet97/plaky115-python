# Security model

See SECURITY.md at the repository root for the full policy: X-API-Key-only
authentication, plk_ redaction, HTTPS-only origins (loopback HTTP for
tests), no automatic redirects, bounded bodies, GET-only retries, no write
retries, sensitive signed URLs, base64-only MCP uploads, curated/read
default MCP posture, and single-tenant HTTP deployment.
